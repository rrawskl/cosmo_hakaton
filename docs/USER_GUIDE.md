# Руководство пользователя Orbital Risk

Версия алгоритма 2.2.1. Сервис сравнивает условия предполагаемого выхода
в открытый космос (ВКД), показывает космическую погоду, потоки протонов
и положение МКС. Результат — оценка по публичным источникам и правилам,
а не разрешение на ВКД или расчёт индивидуальной дозы.

## Первый расчёт

1. Откройте http://127.0.0.1:3000 при работающих backend и frontend.
2. Выберите текущий режим, ближайшее будущее начало, длительность 6 ч
   и поиск альтернатив 12 ч.
3. Нажмите «Рассчитать окно». Дождитесь результата.
4. Прочитайте рекомендацию, статус исходного окна и ограничения.
5. Откройте «Сравнение окон», затем «Доказательства» для объяснения результата.

Все даты вводятся и отображаются в **UTC**. Для московского времени вычтите
3 часа: 16:00 в Москве соответствует 13:00 UTC. Поле даты не переводит
введённое местное время автоматически.

## Параметры

| Поле | Что задаёт |
|---|---|
| Режим current | Оценку по доступным сейчас прогнозам и наблюдениям |
| Строгий replay | Историческую оценку только по сведениям, опубликованным не позже отсечения |
| Historical review | Ретроспективный разбор без гарантии доступности всех сведений на момент решения |
| Начало ВКД | Начало исходного окна |
| Длительность | Длительность каждого сравниваемого окна, от 1 до 8 часов |
| Поиск альтернатив | Допустимое смещение начала вперёд, от 0 до 24 часов |
| Отсечение | Последний допустимый момент публикации данных в replay; не позже начала ВКД |

Сервис проверяет три начала: исходное, середину и конец горизонта.
Например, при начале 13:00, длительности 6 ч и горизонте 12 ч получаются
13:00–19:00, 19:00–01:00 и 01:00–07:00 UTC. Это три кандидата,
а не поиск по каждой минуте. При горизонте 0 оценивается одно окно.

Проверенный исторический диапазон — май–июнь 2024. Для демонстрации replay:
начало 10.05.2024 13:00 UTC, отсечение 10.05.2024 12:30 UTC,
длительность 6 ч, поиск альтернатив 12 ч.

## Экраны и показатели

| Раздел | Назначение |
|---|---|
| Обзор | Итог, исходное окно, факторы, орбита и ограничения |
| Временная шкала | Когда внутри выбранного окна применимы предупреждения, прогнозы и свет/тень |
| Сравнение окон | Оценки равных по длительности кандидатов; выбор карточки меняет рассматриваемое окно |
| Доказательства | Факты, интервалы применимости, источники и объяснения правил |
| Полоса источников | Доступность поставщиков; подробные ошибки и времена доступны в статусе источников |
| Траектория и условия работ | Рассчитанные положение, высота и освещённость МКС; ползунок и воспроизведение меняют момент |
| Протонная панель NOAA GOES | Наблюдения за 6 ч, 1, 3 или 7 дней; каналы, тренды, пики и время измерений |

Кольцо «3/3» означает число факторов с данными, **не вероятность безопасности**.
Kp характеризует геомагнитную активность; R1–R2 и R3 — вероятности категорий
радиозатмений из прогноза. Вероятность S1 в карточке — суточный прогноз
протонного события. Даже небольшая ненулевая вероятность по правилам сервиса
даёт «Требует внимания»; это не утверждение, что буря уже идёт всё окно.

Каналы ≥10, ≥50 и ≥100 MeV показывают интегральные потоки протонов выше
указанной энергии. Единица pfu — частицы/(см²·с·ср). Это вложенные каналы,
их нельзя складывать. Шкала S1–S5 вычисляется по каналу ≥10 MeV;
для ≥100 MeV есть отдельный порог внимания 1 pfu. График логарифмический.
Тренд описывает прошедший час, а пик — максимум выбранного диапазона.

**Текущие наблюдения и будущий прогноз отвечают на разные вопросы.**
NORMAL в панели GOES и «Требует внимания» для будущего окна могут одновременно
быть верны: сейчас превышения нет, но официальный прогноз допускает событие.
GOES не измеряет дозу космонавта на МКС. Свет/тень описывает условия работы
и не повышает или понижает итоговый риск.

## Как читать результат

| Результат | Значение |
|---|---|
| Без триггеров правила | В покрытом данными окне не сработали установленные условия внимания |
| Требует внимания | Сработал порог, применим прогноз ненулевой вероятности или предупреждение |
| Неблагоприятно | Сработало соответствующее неблагоприятное правило; смотрите доказательства |
| Предпочтительный вариант | Один кандидат лучше остальных по установленному порядку сравнения |
| Варианты равнозначны | Нет единственного лучшего кандидата; сравните карточки, это не означает отсутствие риска |
| Несколько лучших вариантов | Только часть окон разделяет лучший результат; номера указаны в объяснении |
| Окно оценено | Расчёт одного окна выполнен, сравнение не запрашивалось |
| Оценка с ограничениями | Есть полезные сведения, но критические данные не покрывают все окна |
| Недостаточно данных | Для содержательной оценки нет необходимых сведений |
| DATA_STALE / DATA_UNAVAILABLE | Измерения устарели / недоступны; это не NORMAL |

При сравнении сначала учитывается наличие неблагоприятных факторов, затем
их длительность, затем длительность внимания. Освещённость не ранжирует окна.
Отсутствие орбиты не блокирует оценку космической погоды и протонов.

## Сохранение и обновление

- «Ссылка» открывает сохранённый расчёт по его идентификатору. Он неизменяемый:
  обновление страницы не пересчитывает старый результат.
- Для свежей оценки задайте параметры и снова нажмите «Рассчитать окно».
- JSON содержит полный результат для программной обработки; PDF — отчёт.
- Повторное воспроизведение через API проверяет расчёт на сохранённых исходных
  ответах без сети. После смены версии алгоритма старая версия может потребоваться отдельно.
- Протонная панель обновляется автоматически; проверяйте время измерения,
  а не только время получения. Обновление источников учитывает их TTL.

## Если результат ограничен

Проверьте даты UTC, покрытие прогноза и статус источников. Далёкое будущее
может выходить за опубликованный прогноз. Повторите запрос после восстановления
источника; уменьшение горизонта помогает только если оставшиеся окна покрыты.
Архив измерений GOES за 2024 не подключён: это ожидаемое ограничение,
исторический прогноз S1 при этом используется. Не заменяйте отсутствующие
данные нулями. Для исторической орбиты нужны Space-Track credentials в локальном
`.env`; они также позволяют использовать резервную текущую орбиту.

Запуск и настройка: [README](../README.md). Точные правила:
[ALGORITHMS](ALGORITHMS.md). Проверки: [VALIDATION](VALIDATION.md).
Локальный адрес доступен на этом компьютере; для внешнего доступа требуется
отдельное развёртывание. Контейнерный запуск с PostgreSQL проверен в GitHub Actions.

## Подготовка к защите

Запускайте `scripts/run_local.py` через Python установленного `.venv`.
Он поднимает оба сервера; окно терминала должно оставаться открытым.
Для презентации откройте [историческое сравнение](HISTORICAL_COMPARISON.md):
там приведены реальные числа NOAA, наши пересечения с окнами и поздние наблюдения.
Не называйте внешние потоки дозой космонавта, а равнозначность критериев —
одинаковым физическим риском. Для геометрии исторического примера настройте
Space-Track в `.env` заранее. Сохранённые анализы локальны: на другой компьютер
они не переносятся вместе с кодом. Экспортируйте PDF/JSON либо перенесите базу
отдельно, сохранив конфиденциальность содержащихся в ней исходных записей.
