# Демонстрация

1. Открыть главную: протонная панель автоматически получает NOAA. Показать
   три энергии, pfu, GOES satellite, роль primary/secondary и timestamp.
2. Поменять 6h/1d/3d/7d, переключить линии, переместить ползунок. Показать
   уровни S только для ≥10 MeV, отдельное ≥100 MeV warning, тренд и пики.
3. Пояснить разницу между текущими наблюдениями и прогнозом будущего окна.
   Запустить current-анализ: общий Kp/R, протоны, орбита и свет/тень.
4. Открыть сравнение одинаковых окон и доказательства. Неполнота будущего
   протонного ряда не заменяется благоприятным статусом.
5. Strict replay: 2024-05-10T13:00 UTC, cutoff12:30. Показать NOAA Issued,
   Space-Track epoch/CREATION_DATE; протонный архив обозначен unavailable.
6. Открыть сохранённую ссылку, JSON/PDF. POST reproduce проверяет тот же результат
   без сети. Старые версии требуют исходного алгоритма и не переписываются.
7. Показать отключение/заморозку источника через env либо закрытый admin API.
   В тестах принудительно проверены timeout и fallback; production не содержит
   сценариев с вымышленными измерениями.
